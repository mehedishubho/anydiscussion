## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Security/Threat-model mitigation] Protocol-relative `//host` URLs rejected by imageUrlSchema**
- **Found during:** Task 1 GREEN
- **Issue:** A literal "starts with /" root-relative check accepts `//evil.com/x.png` — a scheme-relative URL the browser/next/image resolves against an EXTERNAL host. Threat register T-Q5-01 (disposition: mitigate) states accepted `/...` values must only ever resolve against the app's own origin; a bare leading-slash check would break that claim.
- **Fix:** `v.startsWith("/") && !v.startsWith("//")` in the refine + a FAIL test case (`//evil.com/x.png`).
- **Files modified:** src/lib/validation/image-url.ts, src/lib/validation/__tests__/image-url.test.ts
- **Commit:** e9c7be8
