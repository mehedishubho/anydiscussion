## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App process → Postgres (pg_dump) | The Next.js Node runtime shells out to pg_dump with the DATABASE_URL (carries DB password) |
| settings table ↔ backup config | Plaintext config + encrypted credential blobs persist in the key-value table |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Information Disclosure | dump.ts pg_dump invocation | high | mitigate | Use execFile with an argv array (NEVER exec/shell string) so the connection-string password is not shell-interpolated; pass env so PGPASSWORD inherits without landing in a shell history. Verified by dump.test.ts asserting argv is an Array. (Pitfall 7) |
| T-08-01b | Tampering | local.ts path traversal | medium | mitigate | assertSafeBaseKey rejects keys containing ".." or absolute paths before fs.writeFile — a crafted key cannot escape BACKUP_LOCAL_ROOT. |
| T-08-SC | Tampering | (no package install in this plan — n/a) | low | accept | This plan adds zero npm packages; googleapis lands in 08-03 (gated). |
</threat_model>
