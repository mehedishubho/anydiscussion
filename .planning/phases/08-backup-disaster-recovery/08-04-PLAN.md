|----------|-------------|
| Admin browser → Server Actions | Dashboard form mutations cross to admin-gated "use server" actions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Elevation of Privilege | backup Server Actions | high | mitigate | requireRole('admin') is the FIRST line of every action (save/get/test/trigger/restore) — UI hiding via sidebar is supplementary only. MUST_NOT_BE_REACHED test proves non-admin never reaches parse/encrypt/DB. (RBAC convention) |
| T-08-04b | Information Disclosure | getBackupSettings read | high | mitigate | redactCredentials applied on read — secret fields return empty, never pre-filled in the form (Pitfall 7). Test asserts secretAccessKey === "" in output. |
| T-08-04c | Tampering / Repudiation | Restore overwrites live data | high | mitigate | Two-step confirmation gate (type-the-DB-name) in the UI BEFORE restoreBackup is called; action still re-checks admin. High-stakes overwrite is operator-witnessed. (D-05) |
| T-08-04d | Spoofing (CSRF) | Google OAuth callback — forged consent callback could install an attacker's refresh token | high | mitigate | getGoogleConsentUrl() generates a random state, stores it in a signed httpOnly short-TTL cookie; the 08-03 /api/auth/google/callback Route Handler rejects (400) on cookie/state mismatch, then clears the cookie. State is unguessable + bound to the admin's browser. (D-02) |
| T-08-04e | Repudiation / Information Disclosure | "Disconnect Drive" deletes only the local token — refresh token stays valid at Google indefinitely | high | mitigate | disconnectGoogleDrive() calls revokeDriveToken(refreshToken) (Google's revocation endpoint) BEFORE deleting the backup.gdrive_creds row — best-effort try/catch so an already-revoked token does not abort local cleanup. Closes the revocation half of D-02. (D-02) |
| T-08-SC | Tampering | (no package install in this plan — n/a) | low | accept | No new npm package. |
