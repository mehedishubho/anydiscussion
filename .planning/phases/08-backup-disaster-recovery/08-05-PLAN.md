## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App process → Postgres (CREATE/DROP scratch DB) | The drill creates + drops backup_verify on the existing managed Postgres via a raw autocommit pg.Client |
| Build image (Dockerfile) → runtime container | Build-time layers must not contain backup secrets; postgresql17-client must be present at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-05 | Tampering | drill CREATE/DROP DATABASE | high | mitigate | Scratch DB created + ALWAYS dropped in a finally (pg_terminate_backend then DROP) — never lingers; CREATEDB-only privilege (not superuser); raw autocommit pg.Client (no transaction — SQLSTATE 25001 guard). drill.test.ts asserts the sequence + no-linger. (RESEARCH Pitfalls 2/5) |
| T-08-05b | Denial of Service | drill load on prod Postgres | medium | accept | Weekly cadence (D-09) against a scratch DB on the existing Postgres; bounded load for a content site. Revisit if drill load becomes a concern (deferred 2nd Postgres option). |
| T-08-05c | Tampering | duplicate cron across replicas | medium | mitigate (document) | v1 single-instance (documented ISR cliff). Code comment + ADR note: a 2nd Coolify replica double-fires cron; v2 = Redis SET NX lease. NOT solved in v1. (RESEARCH Pitfall 3) |
| T-08-SC | Information Disclosure | backup secrets in Docker image | high | mitigate | No backup credential in any Dockerfile ARG/ENV (D-21 boundary); scripts/check-backup-secrets.mjs grep gate fails the build if a backup secret var name appears in ARG/ENV. All creds runtime-injected by Coolify. (RESEARCH Pitfall 6) |
| T-08-SC2 | Tampering | postgresql17-client apk install | medium | mitigate | Alpine edge/main is the official package repo (RESEARCH Pitfall 1 cites pkgs.alpinelinux.org); pinned major 17 to match the PG17 server. No npm package install here. |
